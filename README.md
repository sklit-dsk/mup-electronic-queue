# MUP Electronic Queue — проектная документация

> **Статус:** концепция / проектирование, v0.1 (2026-10-15).
> **Важно:** независимая инициатива; внедрение, правила приема и работа с персональными данными **не согласованы с MUP**.

Проект электронной очереди для обращений иностранцев в MUP Черногории. В первой версии планируется запись **на выбранную дату без определённого времени**, максимум **100 электронных записей за день**, проверка записи сотрудником **непосредственно у окна**. Рабочий интервал 08:00–14:00 — исходное проектное допущение, расписание конкретного отделения следует подтвердить.

## Локальный сайт документации

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell:
# .venv\Scripts\Activate.ps1
pip install -r requirements-docs.txt
mkdocs serve
# Для проверки: mkdocs build --strict
```

Локальный адрес: http://127.0.0.1:8000.

## Статус решений
Согласованы в **рабочем обсуждении проекта**: запись на дату без времени, лимит 100, проверка у окна. Роли, набор полей и реализация помечены как предложения. Загрузка паспорта, OCR и ИИ — исследуемые опции, **не часть согласованного MVP**.

## Безопасность
Нельзя добавлять настоящие паспорта, персональные данные посетителей, ключи, токены, .env, дампы БД или чувствительные скриншоты. Репозиторий приватный; публичное размещение сайта отдельно не согласовано. Для демонстрации используются синтетические данные.
