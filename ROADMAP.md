## Контрольные точки

- После T00: проект запускается, бизнес-функций ещё нет.
- После T05: сквозное демо очереди, только синтетические документы.
- После T08: фото/OCR и лист ожидания проходят проверки; это ещё не доказательство подлинности паспорта.
- После T10: административные сценарии и удаление данных.
- После T12: отчёт DEMO READY / PILOT BLOCKED либо готовность к отдельно согласованному пилоту.

## Особые зависимости

T09 может быть PARTIAL из-за отсутствия выбранного SMS-провайдера. T10–T12 разрешено выполнять для demo с явно зафиксированным блокером, но они не снимают блокировку pilot. T11 может остаться BLOCKED по инфраструктуре: локальные проверки допустимы, подтверждение развёртывания не выдумывать.

## Критерий DONE для любой задачи

Реализовано, необходимые проверки выполнены и их результаты записаны; нет новых известных нарушений инвариантов; документация и фактический код согласованы. Не расширять задачу до всего проекта.
