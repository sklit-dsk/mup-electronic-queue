# Инструкции для Codex и разработчиков
Статус: рабочая документация v0.1. Проект — независимая инициатива, не официальная система MUP.

## Источники истины
1. Согласованные бизнес-правила и принятые ADR.
2. SRS.
3. Остальная документация.
Гипотезы не становятся требованиями автоматически.

## Согласованные ограничения концепции
- Рабочее окно, принятое для проектирования: 08:00–14:00 (уточнить по конкретному отделению).
- Дневной лимит: 100 электронных регистраций.
- Запись на дату, без выбора времени.
- Проверка записи сотрудником у окна, без отдельного человека на входе.
- Загрузка фото паспорта и ИИ/OCR — только после отдельного решения и оценки рисков.

## Перед кодом
Привязывать изменения к FR/BR/NFR; при неизвестных правилах не додумывать, а пополнять open-questions.md. Обновлять документацию, тесты и ADR одновременно с поведением. Тестировать конкурирующие записи при лимите, повторную отправку запроса, контроль доступа, защиту данных. Для тестов — только вымышленные данные. Никаких персональных документов, секретов, дампов БД в Git. Не публиковать сайт документации без разрешения. Основной язык рабочих материалов — русский, внешний — черногорский после согласования. Часовой пояс приложения: Europe/Podgorica.
