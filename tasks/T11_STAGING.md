## Сделать

- Подготовить deployment Compose/proxy, HTTPS-конфигурацию, healthchecks и отделённые secrets.
- Проверить backup/restore БД, файлов и ключей на чистом закрытом стенде с синтетическими данными.
- Описать runbook сбоя, закрытия дня, восстановления jobs и проверки лимитов после restore.

## Критерии готовности

- [ ] Один воспроизводимый запуск и восстановление; приватные файлы не раздаются static server.
- [ ] Не использовать homelab/публичный домен автоматически; реальная публикация только по отдельному поручению.
- [ ] Записаны точные команды/результаты; STATUS и затронутые контракты обновлены.

## Граница

При отсутствии инфраструктуры закончить deployment-пакет и оставить проверку стенда BLOCKED, не отмечать PASS.

## Завершение

DONE только при выполненных критериях. При внешнем блокере — PARTIAL/BLOCKED с точной причиной и проверяемым остатком. Не переходить автоматически к следующей задаче.
