# Начать здесь

1. Установи или запусти Docker Desktop.
2. Открой эту папку в VS Code.
3. В терминале выполни `docker compose up --build`.
4. Открой http://localhost:8080.
5. Войди как заявитель через DEMO и запишись с синтетическим паспортом.
6. Переключись на сотрудника и пройди вызов → оригинал → начало → завершение.

Это реализованный локальный MVP. Код не нужно генерировать заново.
Полная инструкция: [README](README.md).
Ограничения: [IMPLEMENTATION](docs/IMPLEMENTATION.md).
Для Codex: [готовый запрос](prompts/01_START.md).

Реальные SMS не подключены. Для проверки используй только тестовые документы.
