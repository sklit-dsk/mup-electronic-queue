# Frontend

Дополняет корневой `AGENTS.md`. Реализация находится в src/.

- React + TypeScript + Vite. Адаптивный интерфейс: сначала телефон, затем рабочее место сотрудника.
- Основной язык интерфейса пилота — черногорский (латиница), второй — русский. Строки вынести в словари; пользовательский текст и подписи паспорта не переводить автоматически.
- Статусы и доступные операции определяет API. Disabled-кнопка не считается защитой.
- Обрабатывать loading/empty/error/offline/session-expired; после 409 обновить состояние, не показывать ложное подтверждение.
- Полные паспортные данные и фото не хранить в localStorage, service-worker cache и аналитике. Очищать превью при выходе.
- Публичное табло содержит только номера и окна. Приватные данные не попадают в общие потоки событий.
- При разработке из корня явно прочитай этот файл: загрузка вложенных инструкций не должна оставаться предположением.
