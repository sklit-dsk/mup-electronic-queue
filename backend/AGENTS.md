# Backend

Дополняет корневой `AGENTS.md`. Реализация находится в app/, миграции в alembic/, проверки в tests/.

- FastAPI + SQLAlchemy + Alembic. Для пилота синхронный SQLAlchemy/psycopg: меньше сложностей с транзакциями; блокирующие операции не исполнять в event loop.
- В domain/services нет FastAPI Request и зависимостей от браузера.
- Booking, cancel, transfer, call-next и waitlist-offer — транзакционные операции с единым порядком блокировок из `docs/04_DATA_MODEL.md`.
- Не использовать `count()` без блокировки как защиту лимита 100. Не полагаться на Redis-замок или один Python-процесс.
- Не расширять транзакцию вызовами OCR/SMS и файловым I/O. События уведомлений записывать в outbox вместе с изменением состояния.
- Для изменений модели создавать миграции; `create_all()` не заменяет их при запуске приложения.
- Каждая выдача фото проверяет полномочия, отделение и область доступа сотрудника. Ответы публичного API не сериализуют ORM-объект целиком.
- Не допускать shared Session между потоками или конкурентными запросами теста.
