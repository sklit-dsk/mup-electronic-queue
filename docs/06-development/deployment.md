# Развёртывание (предложение)

Для демонстрации допустима отдельная Docker Compose конфигурация с тестовой базой.

## Требования до запуска
1. Отдельные контейнеры приложения и БД, хранение секретов вне Git.
2. TLS и защита операторского интерфейса.
3. Резервное копирование и процедура восстановления.
4. Мониторинг ошибок и доступности без логирования чувствительных полей.
5. Тестирование на синтетических данных.
6. Запрет публичной публикации без явного решения.

Существующий домашний сервер допустим только для демонстрации с фиктивными данными, не для реальной обработки паспортов без отдельной оценки безопасности.
