# Сценарий посетителя (проект)

1. Открыть форму электронной очереди.
2. Выбрать доступную дату без точного времени.
3. Указать согласованные минимальные сведения.
4. Получить подтверждение, если лимит на дату не исчерпан.
5. Прийти в часы приёма с подтверждением и необходимыми документами.
6. Передать подтверждение сотруднику непосредственно у окна.

Порядок вызова и идентификации пока обсуждается. Этот документ не является действующей инструкцией MUP.
