# Сценарий сотрудника окна (проект)

1. Войти с индивидуальными полномочиями в рабочую панель.
2. Проверить предъявленное подтверждение записи.
3. Сверить информацию согласно согласованной процедуре.
4. Зафиксировать результат обслуживания в системе.

Проверка осуществляется у окна, отдельный проверяющий на входе не требуется. Набор статусов, полномочий, действий и критериев сверки нуждается в подтверждении.
