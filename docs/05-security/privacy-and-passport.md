# Безопасность и обработка персональных данных

**Ключевой риск:** система может обрабатывать идентификационные сведения иностранцев. Законные основания, роли участников, сроки хранения и обязательные меры необходимо проверить с профильными специалистами Черногории **до** сбора реальных данных.

## Базовые принципы
Минимизировать данные; применять контроль доступа, HTTPS, аудит, резервные копии с защитой и сроки удаления. Не сохранять паспортные изображения без отдельной необходимости и правовой оценки. Секреты не хранятся в репозитории. Для демо — только синтетические данные.

## Проверка паспорта с ИИ
Предлагается лишь как исследуемая функция. OCR может извлекать текст, но не доказывает подлинность; автоматизированная модель может ошибаться. Не ставить отказ/запрет на автоматическое решение без понятной процедуры человеческого пересмотра.

## До реального использования
Уточнить контролёра/обработчика, основание обработки, информирование заявителя, обработку трансграничной передачи, сохранность и удаление данных, проведение необходимой оценки рисков и согласование с MUP.
