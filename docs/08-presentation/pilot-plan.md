# План пилота (предложение)

## Условия старта
Согласование учреждения, процессов, политики данных, ответственных и критериев успеха.

## Этапы
1. Демонстрация без реальных посетителей.
2. Совместная проверка сценариев, часов, лимитов и очередности.
3. Исправление выявленных вопросов.
4. Ограниченный пилот только с разрешения учреждения и с необходимыми правовыми условиями.
5. Сбор обезличенных показателей и решение о дальнейшем масштабировании.

## KPI (предложения)
Количество успешных записей, доля неявок, ошибки оператора, время у окна, доступность сервиса, удовлетворённость посетителей.
