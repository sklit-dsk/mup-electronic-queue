# ADR-0002 — 100 регистраций в день

- **Статус:** принято в рабочей концепции.
- **Дата:** 2026-10-15.

## Решение
Первая версия ограничивает успешные электронные записи 100 на дату.

## Мотив
Простой стартовый параметр для MVP, не подтверждённая фактическая мощность отделения.

## Последствия
Необходимы атомарность, проверка конкурентных запросов и правила для отмен/неявок/изменения лимита. Лимит может быть пересмотрен после пилотных измерений.
